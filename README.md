## Add the showreel to the résumé

Add a hyperlink labelled **Watch Paint / Prep Showreel** with this destination:

https://harshvb20.github.io/manikandan-resume/showreel/

The viewing page has a mobile-friendly video player, a download link, and the music attribution. Export the edited résumé as a PDF with hyperlinks enabled, then replace `resume.pdf` as described below.

## Update Manikandan’s résumé

1. Name the updated PDF **resume.pdf**.
2. Open [this repository](https://github.com/harshvb20/manikandan-resume) and select the **main** branch.
3. Choose **Add file → Upload files** and upload the replacement `resume.pdf` to the repository root.
4. Click **Commit changes**. GitHub Pages deploys the update automatically.
5. Allow a few minutes for deployment and caching, then check the permanent link. Updates can take up to 10 minutes to appear.

Keep the GitHub username, repository name (`manikandan-resume`), and `resume.pdf` filename the same. Future PDF updates use the same QR code.

## Update the showreel

Replace `showreel/showreel.mp4` with the updated MP4 and commit the change. Replace `showreel/cover.jpg` if the cover changes, and update the music credit if needed. Keeping the viewing-page URL the same preserves the link in the résumé.

## Site files

- `index.html` — opens Manikandan’s current résumé PDF.
- `resume.pdf` — the current résumé.
- `resume-qr.png` — high-resolution QR image for sharing and printing.
- `resume-qr.svg` — vector QR image for printing at any size.
- `showreel/index.html` — the showreel viewing page.
- `showreel/showreel.mp4` — the uploaded share-quality showreel.
- `showreel/cover.jpg` — the video cover image.
- `.nojekyll` — enables direct static-file hosting.

GitHub Pages publishes from **main / (root)**.
